## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-remove`
- `allow-retrieve`
- `allow-store`
- `allow-store-key-bytes`
- `allow-get-key-bytes`
- `allow-delete-key-bytes`
- `allow-has-key-bytes`
