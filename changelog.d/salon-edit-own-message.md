### Added - you can edit your own text messages in a community salon

The "Modifier" entry was missing in salons only because it had never been built there; an edit is now a silent encrypted row (no push, no server change) that every member checks is from the message's author, so a moderator can delete but not rewrite. See [chat](docs/wiki/frontend/modules/chat.md#editing-your-own-message-in-a-salon-2026-10-05).
