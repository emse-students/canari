### Added - an Alumni duplicate is an admin queue: a push and a bell row to every admin once, a live count, cleared when one admin marks it for a merge

The Alumni duplicates were the one admin page outside the queue mechanism of 2026-11-18. A duplicate is now flagged when found and told once to every global admin with no name, counted on the Administration entry and on its row, and gone for everyone as soon as one admin marks it or answers "Pas un doublon" (an alumnus nobody on the CAS side matches is no duplicate; a notice a failed call lost is told again at the next reading) ([admin](docs/wiki/frontend/modules/admin.md#pending-counts-and-the-admin-notices-owner-2026-11-18)).
