### Changed - a seat is written against a durable eviction record, every key-group departure takes one path, and `POST /mls/commit` is rate-limited per user

Every write that creates or evicts a seat shares one per-group lock and the `dm_seat_evictions` row (chat-delivery migration 036), with no HTTP call under the lock. Every key-group departure, account erasure included, goes through one function that records its outcome (social migration 108), which the hourly drain reads instead of the entitlement. The commit route answers `429` with its wait past 600 commits per user per minute; the client stops its sweeps until then, and warns when the server refuses a membership report ([channel-encryption](docs/wiki/protocols/channel-encryption.md#wp-21-and-the-gate-it-had-nowhere-to-live)).
