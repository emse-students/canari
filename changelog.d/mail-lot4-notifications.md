### Added - a notification for each new school mail, behind a switch that is off

"Notifications de nouveaux mails" (off by default): a Zimbra wait set says when the mailbox changed, and a cursor kept on the device says what is new, so each mail is notified once; Android holds a foreground service, iOS asks at background refresh, web and desktop while open ([mail-client-transport](docs/wiki/mail-client-transport.md#as-built---lot-4)).
