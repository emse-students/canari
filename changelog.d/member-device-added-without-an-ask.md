### Fixed - a member's new device is added, never put up for approval

A new device of someone already in a conversation used to show "Nouvel appareil de X - Ajouter / Refuser", in a 1:1 too, and that line became every conversation's preview. It is now added automatically and everyone sees "X a ajouté un appareil", never as the preview; only a new person is still asked about ([mls-protocol](docs/wiki/protocols/mls-protocol.md#a-device-of-a-member-is-added-never-asked-about-2026-10-31)).
