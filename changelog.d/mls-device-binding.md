### Security - a KeyPackage is checked against the device it was fetched for; device keys are pinned on first sight

A re-add no longer removes a device's leaf for a package that cannot be bound to it, and every device admission in a signed commit is recorded for the new-device notices the user decided on 2026-10-22. See [mls-protocol](docs/wiki/protocols/mls-protocol.md#device-binding).
