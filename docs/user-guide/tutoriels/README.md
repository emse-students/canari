# Tutoriels Canari - le standard et le plan

Support de communication, de publicite et d'information : un PDF court par fonctionnalite, plus un
guide d'ensemble "Decouvrir Canari". Sources redigees dans Docs Claude, exportees en PDF.
Captures prises sur `dev.canari-emse.fr` avec des comptes de test et des donnees fictives
(le depot est PUBLIC : jamais une vraie personne, un vrai identifiant, un vrai message).

Regle de capture (user, 2026-11-01) : la banniere "Environnement de test" est fermee par sa croix
avant chaque capture, a chaque page (elle revient a chaque navigation).

## Le standard (tire de "Creer un formulaire" et "Publier un evenement")

1. En-tete de page : "Canari - Tutoriel" a gauche, logo a droite. Pied : numero de page.
2. Page de garde : oiseau, titre (verbe a l'infinitif), "Version du JJ/MM/AAAA", sommaire.
3. **Pour qui ?** : une ligne (membre, secretaire, tresorier, BDE) et la permission requise.
4. **Contexte** : le probleme vecu, ce que Canari change, ce que ce n'est pas.
5. **Solution proposee** : pas a pas, une capture par etape, mots de l'interface en gras.
6. **Bon a savoir** : limites, pieges (ex. "une modif de date redemande la validation du BDE").
7. **Pour aller plus loin** : liens vers les tutos voisins.
Longueur cible : 3 a 5 pages.
